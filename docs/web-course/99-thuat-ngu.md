# Từ điển thuật ngữ Web và IoT

| Thuật ngữ | Giải thích ngắn |
|---|---|
| Accessibility | Khả năng người khuyết tật sử dụng sản phẩm, thường viết tắt a11y |
| API | Giao diện để phần mềm giao tiếp với phần mềm khác |
| Attribute | Giá trị trạng thái trong một Matter cluster |
| Authentication | Xác minh danh tính |
| Authorization | Kiểm tra quyền được phép làm gì |
| Backend | Phần chạy trên server/gateway, xử lý dữ liệu và nghiệp vụ |
| Broker | Server trung gian nhận và chuyển MQTT message |
| Build | Biến source thành artifact có thể chạy hoặc triển khai |
| Bundle | Gộp module thành ít file JavaScript tối ưu cho phân phối |
| Cluster | Nhóm command và attribute theo một chức năng Matter |
| Command | Yêu cầu một hành động |
| Component | Khối giao diện độc lập, tái sử dụng được |
| Contract | Quy ước có thể kiểm tra về hình dạng dữ liệu giữa các hệ thống |
| Correlation ID | ID nối response với request tương ứng |
| CSS | Ngôn ngữ mô tả cách trình bày tài liệu HTML |
| DevTools | Bộ công cụ debug được tích hợp trong browser |
| DOM | Cây object mà browser tạo từ HTML |
| Endpoint | Một chức năng logic bên trong Matter node |
| Event | Thông báo một việc vừa xảy ra |
| Event loop | Cơ chế JavaScript điều phối callback, timer và I/O |
| Frontend | Phần giao diện chạy trong browser |
| Gateway | Máy hoặc service nối các miền giao thức/hệ thống |
| HTML | Ngôn ngữ đánh dấu cấu trúc nội dung Web |
| HTTP | Giao thức request/response phổ biến của Web |
| Idempotency | Xử lý lặp cùng request nhưng không tạo tác dụng phụ ngoài ý muốn |
| JSON | Định dạng text biểu diễn object, array và giá trị cơ bản |
| Matter | Chuẩn ứng dụng interoperable cho thiết bị Smart Home |
| Module | File hoặc đơn vị code có import/export rõ ràng |
| MQTT | Giao thức publish/subscribe nhẹ, phổ biến trong IoT |
| Node | Thiết bị logic trên Matter fabric |
| Node.js | Runtime JavaScript ngoài browser |
| npm | Package manager và script runner của hệ Node |
| OTBR | OpenThread Border Router chạy trên host Linux |
| Payload | Phần dữ liệu nghiệp vụ của message |
| Pinia | Thư viện state management chính thức cho Vue |
| Promise | Object đại diện kết quả bất đồng bộ trong tương lai |
| Prop | Input cha truyền xuống Vue component con |
| Publish | Gửi MQTT message vào topic |
| QoS | Mức bảo đảm giao message trong MQTT |
| RCP | Radio Co-Processor, xử lý radio Thread và giao tiếp Spinel với host |
| Reactive | Dữ liệu thay đổi làm phần phụ thuộc tự cập nhật |
| Registry | Bảng ánh xạ key sang handler hoặc implementation |
| Retained message | Message cuối được broker lưu cho subscriber mới |
| Schema | Mô tả có thể validate về hình dạng và giới hạn dữ liệu |
| Serialize | Chuyển object thành dạng truyền/lưu được |
| State | Dữ liệu thay đổi quyết định giao diện hoặc hành vi |
| Store | Nơi quản lý shared state |
| Subscribe | Đăng ký nhận MQTT message của topic |
| TailwindCSS | Framework utility-first CSS |
| Thread | Giao thức mạng mesh IPv6 công suất thấp cho IoT |
| TLS | Lớp mã hóa và xác thực kết nối mạng |
| Topic | Tên kênh logic MQTT |
| TypeScript | JavaScript có hệ thống kiểu kiểm tra lúc phát triển |
| Validation | Kiểm tra input tuân theo quy tắc |
| Vite | Dev server và build tool hiện đại cho frontend |
| Vue | Framework xây giao diện reactive theo component |
| WebSocket | Kết nối hai chiều lâu dài giữa browser và server |
| Zod | Thư viện khai báo schema và validation runtime TypeScript |
