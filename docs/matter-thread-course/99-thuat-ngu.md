# Từ điển Matter và Thread

| Thuật ngữ | Giải thích |
|---|---|
| 6LoWPAN | Nén/thích nghi IPv6 cho frame 802.15.4 nhỏ |
| Attribute | State field trong cluster |
| Border Router | Router nối Thread mesh với IP backbone |
| CASE | Session Matter vận hành dựa trên certificates |
| Cluster | Nhóm attributes, commands và events |
| Commissioner | Controller thực hiện onboarding node |
| DAC | Device Attestation Certificate |
| Dataset | Credential và parameters của Thread network |
| Endpoint | Chức năng logic trong Matter node |
| Fabric | Miền tin cậy Matter có CA, identities và ACL |
| HDLC | Framing cho Spinel byte stream |
| Leader | Thread role quản lý partition network data/router IDs |
| Matter | Application protocol và device model trên IPv6 |
| Node ID | Identity vận hành của node trong fabric |
| OMR | On-Mesh Routable IPv6 prefix quảng bá qua Border Router |
| OTBR | OpenThread Border Router host software |
| PASE | Passcode-authenticated session khi commissioning |
| PSKc | Thread Commissioner credential dẫn xuất |
| RCP | Radio Co-Processor xử lý radio 802.15.4 |
| Spinel | Protocol giữa OpenThread host và RCP |
| Subscribe | Interaction tạo periodic/change reports |
| Thread | IPv6 mesh protocol trên 802.15.4 |
| TREL | Thread Radio Encapsulation Link trên IP backbone |
| wpan0 | Linux interface do OpenThread host tạo |
